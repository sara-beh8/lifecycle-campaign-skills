# Brand voice config — Acme Helpdesk (example)

Replace with your company's rules. The copy skill treats this file as law.

## Tone
- Plain, direct, benefit-first. Write like a helpful operator, not a brochure.
- Second person ("you"), present tense, active voice.
- No exclamation marks in body copy; max one in a subject line per quarter (joke — but treat them as expensive).

## Banned
- "revolutionary", "game-changing", "unlock", "supercharge", "seamless"
- Fake urgency ("last chance!") unless a real deadline exists
- Claims without a citation in `product-facts.yaml`

## Formatting
- Subject ≤ 50 chars · preview text ≤ 90 chars
- Body: 3 blocks max — value, proof, action
- One primary CTA button; links deep-link to the product action, never the homepage
